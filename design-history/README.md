# Design history

The three directions explored before the site landed on its current look. They
are kept because `DESIGN.md` cites them as the reasoning behind the chosen
direction, and because the rejected options explain constraints that would
otherwise look arbitrary.

- `functionalist_specimen.md` — the direction that was chosen, light variant
- `functionalist_precision.md` — rejected
- `industrial_minimalism.md` — rejected

The full exploration, including 55 mockup screenshots and the generated
`code.html` prototypes, was 15 MB and lived in this repo as `miomir design
system/`. It was moved out on 2026-08-17 to keep the repository light, since
the VPS clones this repo on every deploy. It now sits outside the repo at:

```
Desktop/Personal/Mine/miomir-design-archive/
```

`miomir-docs.tar.gz` was archived to the same place on 2026-08-17. It held a
504 KB snapshot of the old four-page site, titled "Systems Engineering &
Applied Research", with a 38-file font subset. The current site supersedes it
and lives in `docs/`.

That folder is not backed up by git. Move it somewhere durable if the mockups
still matter to you.
